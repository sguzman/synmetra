# 🎨 Synmetra OKLab/OKLCH identity

**Perceptual accent:** sea-glass / measured teal-green, chosen to evoke analysis rather than alerts.

- CSS `oklch(72% 0.12 184)`
- Approximate OKLab `L=0.720, a≈-0.1197, b≈-0.00837`
- sRGB conversion, 8-bit rounded `#28BDAD` (sRGB gamut-safe)
- Recommended swatch ink `#092E35` contrast **6.17:1** against the brand accent (WCAG AA normal text threshold 4.5:1)
- White against the accent yields only **2.34:1**: **do not** use white text over the swatch
- Dark ink `#092E35` on off-white `#F0FCFA`: ~**13.76:1**

This local OKLCH identity is intentionally separated from Posthorn's amber-orange (`#E5923C`, hue ≈63°), Typefinch's periwinkle (`#8696F5`, hue ≈275°), and Rust-Age's iron oxide (`#E05B4C`, hue ≈29°). Pairwise/global registries and dark/high-contrast graphical themes still require their own test gates. The project color never signals a task's completion status.
